# v1.2 Deterministic Ingest Implementation Note

> This is an implementation note for v1.2. The frozen v1.0 architecture,
> data contract, and runtime / failure contract remain authoritative.

## Objective

Build the side-by-side deterministic ingest foundation:

```text
configured Sources → collector → normalizer → article_dedup → canonical Article[]
```

Generation 1 production remains unchanged. This milestone does not implement
event clustering, semantic selection, LLM stages, rendering, orchestration, or
production routing.

## Implementation shape

- `collector.py` owns source configuration, RSS fetching, raw entry extraction,
  and source-scoped `StageResult` isolation.
- `normalizer.py` owns deterministic raw-entry validation and construction of
  `canonical_domain.Article`.
- `article_dedup.py` owns exact duplicate removal by canonical URL or article
  identity, retaining the first valid ingest occurrence.
- `tests/offline_deterministic_ingest_smoke.py` uses fixtures and injected
  fetchers/clocks only; it never calls external RSS or APIs.

The collector retains one successful source batch per source, including an
empty batch. Normalization expands those batches into raw entries. This keeps
the frozen `StageResult.partial` invariant expressible when one source is
empty-successful and another source fails.

## Canonical authority and boundaries

- `canonical_domain.Article` is the only Article schema.
- Canonical URL, Article identity, language vocabulary, and UTC datetime
  validation are reused from `canonical_domain.py`.
- Feed `mode`, `role`, `category`, keyword rules, importance, relevance, and
  other Generation 1 metadata are not carried into canonical Articles.
- Raw feed payloads remain temporary collector/normalizer inputs and are not
  persisted in Article fields.
- Exact Article dedup never uses title similarity, embeddings, event
  clustering, or semantic judgment.

## Verification commands

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python tests/offline_deterministic_ingest_smoke.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python tests/offline_canonical_domain_smoke.py
PYTHONPYCACHEPREFIX=/private/tmp .venv/bin/python -m py_compile canonical_domain.py collector.py normalizer.py article_dedup.py
git diff --check
```

## Success criteria

- Source failures are isolated and represented with the frozen failure codes.
- Legal empty source results are successful; all successful source batches are
  retained for downstream coverage accounting.
- Naive or malformed timestamps fail closed at the item boundary; timezone-aware
  timestamps normalize to UTC.
- Canonical Articles contain only frozen fields and have stable IDs.
- Exact duplicates are deterministic and cross-source same-event reports remain
  separate.
- No dependency, Generation 1 production behavior, or external project file is
  changed.
